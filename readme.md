## Total Commander Lister plugins

This repository contains of the following **Lister plugins** written in [Delphi](https://en.wikipedia.org/wiki/Delphi_(software)).
- **LineLister** to display text files, e.g. program sources, with line numbers
- **SvgViewer** to display SVG images (*Inkscape* is **not required**)
