## LineLister 
### Total Commander Lister plugin

This plugin adds a **column of line numbers** to the left margin of the standard text view. This makes program source code, in particular, much easier to read and facilitates to find specific sections.

#### Additional features:
- The built-in search function automatically recognizes the word the cursor is currently on.
- You can jump directly to a specific line by entering its number.
- The text encoding (ANSI, OEM (437), UTF-8, and UTF-16) is automatically detected. Files that are not recognized as text are automatically displayed using the default lister function (e.g., as binary or graphics).
- Optionally, you can specify a list of file types (file extensions) that should be displayed using this plugin. For all other file types, the default listing functions are used.
